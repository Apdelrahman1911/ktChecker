# Optional Ktlint syntax adapter

`KtlintProvider` is an isolated, opt-in, lint-only adapter for pinned Ktlint 1.8.0
and Compose rules 0.6.8. It retains all 137 catalog aliases, routes 131 exact syntax
IDs, and refuses excluded/refined aliases. These numbers are mappings, not
detector-test or compatibility claims.

The default authority denies execution. An owner-selected installation and an
exact immutable-snapshot `ExecutionPermit` are required. Only the declared
Kotlin 2.2.21/JDK21 JVM syntax profile has verified Linux x86_64 native-supervised
fixture execution: **18/18 tests**, eleven confirmed children and one exact
authorization-denial callback in the corrected redirected 2026-11-04 rerun.
Four specific provider/context rows are locally tested, not qualified; historical
pre-native attribution remains withdrawn and archived. Kotlin 2.4.21 and other
platform profiles abstain. No source formatting, engine/plugin loading into the
host, automatic downloads or clean-coverage certificates are provided.

See [the fixture documentation](../../providers/ktlint-fixtures/README.md) for
installation, opt-in real-process tests, EditorConfig boundaries, evidence and
remaining qualification gaps.
